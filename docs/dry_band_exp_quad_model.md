# 乾物バンド × exp/quad 加法モデル（高含水外挿）(2026-06-26)

> **【廃止 2026-06-27】** 本記録の quad×exp アンサンブルは廃止。複数特徴の相乗効果(交互作用)を
> 内側に入れた単一モデル `exp(Σβz+Σγz_iz_j)` が macro 25.6 と本アンサンブル(25.86)を上回ったため。
> 後継: [dry_band_exp_synergy_model.md](dry_band_exp_synergy_model.md)。以下は経緯として残す。

高含水域(MC>120%)で**水バンドが吸収飽和して情報を失う**一方、**乾物(C-H)バンドは質量
希釈で抑制され続け高MCの勾配を保つ**という知見([dry_band_stat_features.md](dry_band_stat_features.md))を、
**非線形当てはめ(exp/quad)を基底にした加法モデル**として実装し外挿性能を検証した記録。
ターゲット ベイスギ(MC298%, 学習上限216%超=外挿)。実装/再現: `notebooks/dry_band_tweedie_twostage_loso.ipynb`。

## 当てはめ関数（§非線形フィットの結論）

`MC = φ(特徴量)` の当てはまり R²(全体 / 高MC域):
- **exp** `A·e^{Bf}+C`: CH1270 で 0.76 / 0.59 と最良。**単調で外挿が安定**。
- **quad** `af²+bf+c`: R²はexpとほぼ同点だが、**先頭係数aの符号で外挿方向が反転**(a<0で高域減少)＝不安定。
- **log** `a·ln(f−f₀)+b`: 全特徴で当てはまり最悪(高域で飽和する曲率＝データと逆)。
- 補足: **目的変数の素朴な log 変換は高MC外挿を悪化**させる(別検証, Ridge log-target でベイスギ65→102)。

→ 採用は **exp 基底**を主、quad を補正に。

## モデル

加法モデル(どちらも標準化→基底化→Ridge、標準化/B_jは各foldの学習側でfit):
- **exp 加法**: `MC = β₀ + Σⱼ βⱼ·exp(Bⱼ zⱼ)`（zⱼ=標準化特徴, Bⱼは1次元exp当てはめで決定）
- **quad 加法**: `MC = β₀ + Σⱼ (βⱼ zⱼ + γⱼ zⱼ²)`
- **シンプルアンサンブル**: `pred = w·exp + (1−w)·quad`

いずれも線形/パラメトリックなので**学習範囲外を外挿できる**（木と違い天井打ちしない）。

## LOSO 結果（13樹種, macro-RMSE, 乾物5特徴）

| モデル | macro | ベイスギ(外挿) |
|---|---|---|
| quad 単独 | 32.28 | **58.04**（外挿最良だがmacro最悪）|
| exp 単独 | 25.99 | 62.16 |
| **アンサンブル w_exp=0.9** | **25.86** | 61.21 |
| アンサンブル w_exp=0.5 | 28.13 | 58.54 |

- **「expを主、quadを1割」(w_exp=0.9)が最良**: macroをexp単独より僅かに改善しつつ、ベイスギも62→61と同時に改善。
- quad単独は外挿最良(58)だが符号不安定で中域を崩しmacro 32と劣化。
- トレードオフは緩く、**実用は w_exp=0.8〜0.9 を事前固定**が無難。

## 位置づけ・注意

- macro絶対値(25.9)は、より多特徴の系([fft_band_stepwise_features.md](fft_band_stepwise_features.md)系の
  24特徴LightGBM=17.6 や 48特徴Huber=19.5)より高い。**本モデルの価値はmacro最小化でなく、
  高MC樹種(ベイスギ)の外挿が木モデル(83前後)より大幅に良い(58–62)点**。中低域は別系統、
  高域はこのexp/quad加法、の**役割分担/ブレンド**が次の自然な設計。
- **リーク注意**: 乾物バンドは「高MC相関」EDA(全train使用)で選定、最適wも全fold集計で選択＝
  どちらも軽い楽観バイアス([loso-validation のネスト化が厳密])。本番は特徴・wを事前固定する。
