# 乾物バンド × ガウス / 区間線形 / 区間多項式 加法モデル(高含水外挿)(2026-06-27)

[dry_band_exp_quad_model.md](dry_band_exp_quad_model.md) で大域非線形当てはめ(exp/quad)を試したが、
**exp は係数の不確実性で発散しうる・quad は先頭係数の符号で外挿方向が反転**という外挿リスクがあった。
そこで大域関数を当てはめず、**局所基底(ガウス基底 / 区間線形=線形スプライン)を各バンドに加法展開**して
Ridge で結合する GAM とし、高含水(ベイスギ MC298%, 学習上限216%超=外挿)を予測できるか LOSO 検証した。
特徴は同一の乾物5バンド×mean。再現: `notebooks/dry_band_gauss_pwlinear_loso.ipynb`(樹種別 真値vsLOSO予測の図あり)。

## 基底(各 fold の学習側のみで分位点ノット決定＝リーク無し)
- **ガウス基底**: 各標準化特徴を K個のガウス `exp(-(z-c_k)²/2σ²)`(中心=学習分位点, σ=ノット間隔×倍率)で展開。
  → 学習範囲外では全ガウスが減衰し**予測が大域平均へ回帰**(外挿不能)。
- **区間線形(線形スプライン)**: 切断べき基底 `{z, (z-t_k)₊}`。
  → 両端は**最外区間の傾きで線形外挿**。exp より穏やか・quad のような符号反転無し。
- **区間多項式(切断べき, 次数d)**: `{z,…,z^d, (z-t_k)₊^d}`。→ 裾は **d 次で外挿**(d≥2 は quad 同様に発散リスク)。
- **自然3次スプライン**: 3次だが**境界ノット外側を線形に拘束** → 内部は曲率、裾は線形外挿(発散しない)。

## LOSO 結果(13樹種, macro-RMSE / ベイスギ外挿, 乾物5特徴)

| モデル | macro | ベイスギ(外挿) |
|---|---|---|
| 線形加法(参照) | 34.63 | 89.3 |
| **ガウス基底 GAM**(best K=4,wmul=1.5,α=0.3)| 30.53 | **69.8**（外挿悪い）|
| **区間3次(普通の区間多項式)** | 32.96〜58 | **71〜128（発散・破綻）** |
| 区間2次 K=8, α=100 | 27.27 | 51.1 |
| exp 単独(既存) | 25.99 | 62.16 |
| exp(相乗)(既存最良) | 25.6 | 58.9 |
| quad 単独(既存) | 32.28 | 58.04 |
| **区間線形 GAM** K=3, α=30 | 25.88 | 50.4 |
| **区間線形 GAM** K=12, α=30 | 27.02 | **48.6** |
| **自然3次スプライン** K=10, α=30 | **25.54** | 51.5 |

- **ガウス基底は外挿に不適**: macro も exp に劣り、ベイスギ 64–72 と悪化。RBF が学習範囲外で 0 へ減衰し
  予測が平均へ回帰するため、高MC を下振れさせる(局所基底の構造的限界。線形加法89よりはマシな程度)。
- **区間線形(線形スプライン)が最良**: **強正則化(α=30)** で macro は exp と同等(25.88 vs 25.99)、
  かつベイスギは **50.4(K=3)〜48.6(K=12)** と exp(62)・quad(58)・exp相乗(58.9)を**大きく上回る外挿**。
  ノット数 K を増やすほどベイスギが単調改善(63→48)し、α↑で macro・外挿が同時改善する。
- 直感: 線形スプラインの**線形な裾**が「乾物バンドが高MC域でも保つ勾配」を素直に外挿でき、
  exp の発散も quad の符号反転も起こさない。**大域非線形より局所線形+裾線形の方が安全かつ高精度**。
- **区間多項式 d=3(普通の区間多項式=3次スプライン)は外挿で発散して破綻**(ベイスギ 71–128, macro 33–58)。
  quad/exp と同じ高次外挿の不安定性が再現。強正則化(α=100)でも 71 止まり。**区間2次**は強正則化で抑えられる(51.1)
  が区間線形に僅かに劣る(z² の裾が悪さをする)。
- **自然3次スプラインが最良**: 境界外を線形拘束するため内部の曲率を活かしつつ裾は安全 →
  **macro 25.54(全基底最小)・ベイスギ 51.5**。「多項式の表現力 × 線形外挿の安全性」の良いとこ取り。
  → **高含水外挿の本質は「裾が線形であること」**。区間多項式の高次の裾は逆効果。

## 特徴探索(乾物バンド限定, 2026-06-27 追記)
基底を自然3次GAMに固定し、乾物(C-H/セルロース・リグニン)領域のバンド×前処理(SNV/SG1/SG2)×統計量
(mean/slope/cr)を候補に探索。水バンド(1450/1940)は除外。

- **データ駆動の貪欲選択(LOSO macro最小化)はリークで幻**: 見かけ macro 19.4 / ベイスギ 30.7 だが、
  ネストLOSO(外側で1樹種を完全に隠し内側だけで選択→評価)では **macro 24.9 / ベイスギ 79.7** と悪化。
  選択は内側樹種に過適合し、**未知の高MC樹種でむしろ外挿が壊れる**(48→80)。→ 特徴選択は外挿に効かない。
- **事前固定の少数セット(ドメイン根拠)には本物の改善**(各値はリーク無しLOSO):
  ORIG5(mean5)=25.54/51.5 を基準に、**mean+slope混合5 = 23.85/43.0**、CH倍音3(1270/1715/2320)=24.77/43.2、
  ORIG5+b1210(C-H第2倍音)=20.42/53.3。slope は中低域の macro と外挿の両方に寄与。
- **採用: mean+slope混合5** = CH1270_mean(SG1), **CH1270_slope(SNV)**, CH2210_mean(SG2), CH2320_mean(SG2),
  CL2360_mean(SNV)。現行ORIG5を両指標で上回る。再実行後の自然3次GAMは macro≈23.2〜24.1 / ベイスギ≈35〜43、
  区間線形は macro 23.7(K3α30)〜 / ベイスギ最小≈30(K6α1)。**区間3次は新特徴でさらに発散**(ベイスギ300超)。
- 注意: ベイスギは1樹種n=60で分散大、43 vs 51 の一部はノイズの可能性。少数案比較ゆえ過信せず事前固定で運用。

## 高含水帯(MC>120%)特化への目的変更(2026-06-27 追記)
本モデルの役割は**高含水帯(MC>120%)専用**(MC≤120 はアンサンブルの他モデル担当)。指標を macro から
**LOSOの MC>120 サンプルRMSE**(全樹種プール, n=146; 内訳 120-200:128 / >200:18)に変更して再最適化。

- **目的を変えると最適も変わる**: 高MCでは**正則化を弱めた区間線形 hinge K=8, α=1** が最良
  → **MC>120 RMSE=28.0**(内訳 **120-200%=26.0 / >200%=39.7** / ベイスギ>120=36.9)。
  macro向きの自然3次 K10α30 は高MCでは劣る(MC>120 RMSE=35.3)。**高MCは区間線形+弱正則化**。
- **特徴は mean+slope混合5 のまま最適**。macroに効いた b1210 は高MCで悪化(>200 が 40→61)するため不採用。
- **高MC重み付け(sample_weight=mc^p)・冪変換ターゲット(MC^{1/p})・凸上裾基底はいずれも無効**(改善せず)。
- **>200% は乾物特徴の飽和で頭打ち**(診断): (1)ベイスギ自身の低MC側で学習→高MC側を予測しても≈118%止まり、
  (2)ベイスギ MC=259〜299% は特徴空間でほぼ同一近傍(他樹種の実MC≈177%)に写る=MC増でも特徴が動かない。
  → 入力が動かない以上、線形/凸/exp どの裾でも持ち上げ不能。「下に凸の裾」も無効。乾物特徴での >200 改善は
  飽和しない別情報(生スペクトルのピーク面積比等)が要る。120-200% はまだ改善余地(現状26)。

## 位置づけ・注意
- 高MC外挿という目的では、本系統(区間線形 / 自然3次スプライン GAM)が現時点で最良(ベイスギ 48–51, macro≈exp)。
  macro 最小化は別系統の多特徴モデル(LightGBM 17.6 等)が依然上。役割は高域担当。
- **リーク注意**: 乾物5バンドは全trainの高MC相関EDAで選定、最良 K/α も全fold集計で選択＝軽い楽観バイアス
  ([loso-validation のネスト化が厳密])。本番は K・α を事前固定する(強正則化 α≈30 が頑健)。
- ノット・幅・標準化はすべて**各 fold の学習側のみ**で fit 済み(リーク無し)。
