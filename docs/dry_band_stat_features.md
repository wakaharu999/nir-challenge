# 乾物(C-H)バンド統計特徴 + 高含水外挿モデル (2026-06-26)

高含水域(MC>120%)で**水バンド(O-H)が吸収飽和して情報を失う**一方、**乾物
(セルロース/リグニンのC-H)バンドは質量希釈で抑制され続けて高MCの勾配を保つ**、
という仮説に基づき、乾物バンドから統計特徴を作って LOSO で外挿モデルを検証した記録。
[fft_band_stepwise_features.md](fft_band_stepwise_features.md) とは別系統の試行。

## 背景 — なぜ乾物バンドか

- 目的変数 含水率(MC)は 0.8〜298%。**ベイスギ(最大298%)が突出**し、次点イチョウ216%。
  LOSOでベイスギを外すと学習データ上限216%超への**外挿**が必要。
- 強い水バンド `sg1 2000-2100|max` は全体 Spearman −0.92 だが、**高MC域(>120%)内では −0.41 に崩壊**。
  同一特徴量値でベイスギMCは他樹種の **2.0倍**(263% vs 129%)= 外挿でなく**飽和**。
- スライディングウィンドウ走査で「高MC域内の相関」を指標にすると、上位は水バンドでなく
  **C-H/セルロース・リグニン由来バンドの微分**だった(下表)。EDAは `notebooks/dry_band_eda.ipynb`。

## 前処理

- ベース: 生スペクトル(nm昇順)。**SNV**(行単位)後に **SG**(`savgol_filter(win=11, poly=2)`)、
  SG1=1次微分・SG2=2次微分。微分は飽和したベースラインのオフセットを除去し残差形状を取り出す。
- 全ての SNV/SG/統計量は**行単位** → 特徴行列はリーク無しで全体一括計算可。モデル(及び標準化)のみ fold 毎学習。

高MC域で|相関|が残る=飽和しない=外挿に使える。上位:

|---|---|---|
| CH1715\|mean (=area) | +0.63 | **+0.65** |
| CH1270\|mean (=area) | +0.71 | +0.61 |
| CH2320\|mean (=area) | +0.46 | +0.60 |

## LOSO モデル比較 (13樹種, macro-RMSE, 48特徴)

スクリプト/notebook: `notebooks/dry_band_loso_models.ipynb`。

| モデル | 種別 | macro | **ベイスギ**(外挿) |
|---|---|---|---|
| Huber (ロバスト線形) | 線形 | **19.5** | 77.6 |
| **exp-Ridge** `MC=exp(Xβ)` | 非線形外挿 | 22.6 | **62.3** |
| RandomForest | 木(外挿不可) | 23.0 | 83.7 |
| Ridge | 線形 | 23.2 | 82.1 |
| LightGBM | 木(外挿不可) | 24.7 | 82.9 |
| **exp-1D** `MC=A·exp(B·f)+C` | 非線形外挿(1特徴) | 29.1 | **56.3** |

- **非線形(exp)外挿モデルが高含水を救う**: ベイスギfold 木83 → exp-Ridge 62 → exp-1D 56。
  指数の関数形が学習上限216%を越えて予測を伸ばせる。木は216%付近で天井打ち。
- **トレードオフ**: 攻めた外挿(exp-1D)はベイスギ最良だが中域(クリ/ヒノキ)を壊しmacro悪化。
  **exp-Ridge が均衡点**(ベイスギ83→62, macroはRF同等)。
- exp-Ridge は内部で「log でfit → exp で逆変換」=`MC=exp(Xβ)`。単純な y=log(MC) 回帰とは別物。
  **目的変数の素朴なlog変換は高MC外挿を悪化させる**ので注意(Ridge log-target でベイスギ 65→102)。
- macro最優先なら乾物バンドの線形性がきれいな **Huber(19.5)**。

## 重要な注意 (リーク)

これらの帯域は「高MC域の相関」EDA(=全train使用)で選んだため、**バンド選択に軽い楽観
バイアス**がある([fft_band_stepwise_features.md](fft_band_stepwise_features.md) と同じ構図)。
統計量計算・標準化・モデルfitは fold 内なのでリーク無しだが、厳密にはバンド選択も各fold内に
入れるネストLOSOで正直な数字を出す必要がある。
